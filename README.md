Solano Bay is an original open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty. Mara Voss, a courier driver, works three story acts across five districts of a sun-soaked coastal city: driving and walking, traffic and pedestrians, cars to steal, a five-star wanted level with police chases, missions and a final heist, on-foot combat, a HUD with a minimap, a start screen and a save. All art is drawn in code and all sound is synthesized with Web Audio — no network, no assets, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
